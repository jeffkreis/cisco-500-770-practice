About this 60-question key

This sitting follows the customer-scenario practice key for exam 500-770. It mixes account-executive commercial questions with systems-engineer technical questions. The key treats 75% as passing, which is 45 of 60. Choose-two, choose-three, and matching items score only when every required selection is right.

Answer letters stay in the order printed in the key. Matching asks you to pair each concept with one outcome, and each outcome can be used once. The printed key sometimes banners a different letter than the keyed answer; this quiz grades from the Answer line.
